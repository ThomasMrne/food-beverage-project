# Modern Data Architecture – Food & Beverage Lab

## Objectif
Construire une architecture data end to end :
- Ingestion de la data (Snowflake)
- Nettoyage & modélisation (Bronze / Silver / Analytics)
- Analyses business
- Data Product prêt pour le ML
- Visualisation Streamlit

## Stack
- Snowflake
- SQL
- Python
- Streamlit

## Structure du projet
(sql / streamlit / analytics)

## Comment exécuter
1. Lancer Snowflake SQL
2. Exécuter les scripts dans sql/
3. Lancer Streamlit
